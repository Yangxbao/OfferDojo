# 路线图（Roadmap）

按阶段规划，每项都是"当前没做、打算做"的真实计划，不虚构已完成的功能。

## 阶段一：夯实基础（当前版本 0.1）

- [x] 前后端骨架、数据库设计、认证与角色
- [x] 214 个内置任务（四档难度）+ 10 阶段学习路线图 + 75 道八股复习题 + 结构化 AI 评估（Mock / Remote 双 Provider + 降级）
- [x] 工作台 / 任务中心 / 练习记录 / 能力分析 / 后台管理
- [x] 单元测试 + 完整业务流程集成测试 + CI
- [x] 追问模拟面试（评估报告里的技术追问可作答，AI 按上下文反馈）
- [x] 八股自测模式（先遮答案再自评掌握度）
- [x] 简历素材草稿生成（基于真实练习记录）与 JD 反向匹配
- [x] 评估报告 Markdown 导出
- [x] 评估可追溯：prompt 版本与原始返回入库
- [ ] 评估报告支持人工复核标记（"我核对过，模型说得对/不对"），沉淀人工纠偏数据

## 阶段二：AI 评估质量（短期）

- [ ] 远程 Provider 的提示词模板外置为可编辑资源（不写死在代码里）
- [ ] 支持"答案对比评估"：同一任务取匿名高分答案作为 few-shot 参考
- [ ] 评估结果缓存与重试队列：相同 (任务, 答案) 哈希的重复评估直接复用
- [ ] 流式输出（SSE）：提交后逐步渲染评估内容，改善等待体验
- [ ] Token 用量统计入 `ai_call_log`，后台可见成本
- [ ] 追问对话的深度收敛：按评分动态决定是否继续追问、生成终面评语

## 阶段三：学习闭环深化（中期）

- [ ] 参考解法库：每题配"参考解法 + 常见错误"（内容工程量大，按高频题优先分批补）
- [ ] 题解对比区：提交后可见同题其他用户的脱敏答案
- [ ] 错题本与间隔重复（SRS）：低分任务/八股按 1/3/7 天进复习队列（八股自测已做自评，SRS 调度待做）
- [ ] 任务 ↔ 八股 ↔ 面试题深度互链（已实现类目级跳转，细化到题目级关联）
- [ ] 多岗位方向：在 Java 后端之外增加前端 / 测试 / 数据方向任务包
- [ ] 邮箱注册与密码找回（当前只有用户名密码）

## 阶段四：工程升级（长期）

- [ ] 引入 Testcontainers，测试环境与 MySQL 完全一致后合并两份建表脚本
- [ ] 引入 Flyway/Liquibase 替代 SchemaMigrationRunner 的轻量迁移
- [ ] 统计预聚合表（评估量级上来后替换实时聚合）
- [ ] refresh token 与登录设备管理（当前 72h 静态过期）
- [ ] Docker 镜像与一键部署（backend + frontend + mysql compose）
- [ ] OpenTelemetry 链路追踪接入（评估链路的耗时拆解）

## 明确不做（YAGNI）

- 微服务拆分、消息队列、分布式锁等分布式组件——单机学习平台用不上
- 用户量/转化率等运营看板——没有真实运营数据，不造假数字
- "AI 能力测评报告"之类的绝对化能力结论——评分仅供练习参考
