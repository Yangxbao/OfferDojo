# OfferDojo 前端静态演示版部署指南（阿里云 OSS）

> 本文档覆盖：本地构建 → 产物上传 → OSS 静态网站配置 → 域名/备案/HTTPS → 费用与安全。
> **静态演示版定位**：展示任务/八股/路线/资源等静态内容 + localStorage 本地进度，不含后端能力。

## 一、静态演示版是什么、不是什么

**是**：220 道任务、125 道八股、三条方向路线、18 条资源中心内容全部可浏览；作答草稿与提交记录保存在**当前浏览器 localStorage**（清除浏览器数据会丢失）；作答后可获得本地进度统计。

**不是**：不含服务器登录（自动使用本地演示身份）、AI 评估、追问模拟面试、社区投稿、项目投稿、GitHub 实时榜单、简历生成、JD 匹配。点击相关功能会看到明确提示「静态演示模式暂不支持」，**不会假装成功**。

页面顶部有醒目的黄色横幅：`静态演示模式：数据仅保存在当前浏览器，未连接正式后端`。

## 三、上传到 OSS

上传 `dist` 目录下的**全部内容**（index.html 与 assets/ 目录）到 Bucket **根目录**。

方式任选：
- **OSS 控制台**：Bucket 概览 → 文件管理 → 上传文件 → 选择 dist 下所有文件（保持目录结构）
- **ossutil 命令行**（需自行配置，本文不涉及密钥）：`ossutil cp -r dist/ oss://你的bucket名/`

**不要上传**：`backend/` 目录、`.env` 文件、任何数据库文件（*.mv.db）、源代码 —— 这些不属于静态站点。

## 四、OSS 静态网站配置（关键）

OSS 控制台 → 你的 Bucket → **数据管理/基础设置 → 静态页面**：

| 配置项 | 值 | 说明 |
|---|---|---|
| 默认首页 | `index.html` | 访问根路径时返回首页 |
| 默认 404 页 / 子目录首页 | `index.html` | **SPA 路由回退的关键**：刷新 `/tasks` 等子路由时 OSS 找不到该文件，回退到 index.html 由前端路由接管 |

> 不开启「子目录首页」时，直接刷新 Vue 子路由（如 `/tasks/5`）会得到 OSS 默认 404 页。开启后即可正常回退。配置后无需重启，即时生效（可能有分钟级缓存）。

Bucket 读权限：**公共读（Public Read）**（静态网站要求可公开访问）；**严禁公共读写**。

## 五、域名、备案与 Bucket 选择（重要）

### 为什么不能直接用现有中国内地 Bucket 绑定域名

中国内地地域的 OSS 通过自定义域名对外提供 Web 服务时，**该域名必须完成 ICP 备案**。`x0707.com` 目前未备案，绑定后访问会被阻断，且 OSS 会要求验证备案号。

### 推荐路径：中国香港 Bucket（免备案）

1. OSS 控制台 → 创建 Bucket → 地域选**中国香港**（或新加坡等非内地地域）→ 存储类型标准 → **公共读**
2. 上传构建产物（同第三节）并配置静态页面（同第四节）
3. 通过 Bucket 概览页的「传输管理/域名管理」绑定自定义域名 `www.x0707.com` —— **CNAME 记录值必须使用控制台实际显示的目标地址**（形如 `your-bucket.oss-cn-hongkong.aliyuncs.com`，以控制台为准，不要照抄本文）
4. 到你的 DNS 服务商添加 CNAME：`www` → 控制台给的目标值

> 香港地域带宽单价高于内地，演示站流量小影响不大；若未来流量增大或完成备案，可迁移回内地 Bucket 并接入 CDN 降低成本。

### 备案后再迁移（可选）

完成 ICP 备案后，可将域名绑回中国内地 Bucket（延迟更低），流程与上述一致。

## 六、HTTPS 证书

1. 阿里云数字证书管理服务可申请**免费 DV 证书**（每个域名每年 20 张免费额度，够用）
2. 证书签发后：OSS Bucket → 域名管理 → 你的自定义域名 → 开启 HTTPS → 选择已签发证书
3. 验证：DNS 添加控制台要求的域名验证记录（具体记录以控制台提示为准）
4. 可同时开启「强制 HTTPS 跳转」

## 七、费用预估（演示规模）

| 计费项 | 量级估算 | 说明 |
|---|---|---|
| 存储 | < 10 MB | 构建产物约几 MB，标准存储单价极低（约 0.12 元/GB/月） |
| 请求 | 每千次 GET 约几分钱 | 演示流量下可忽略 |
| 公网流量 | **主要成本** | 香港地域约 0.5 元/GB 量级；每次页面加载约几 MB |
| HTTPS 证书 | 免费 DV 证书 0 元 | 每年 20 张免费额度 |

**查看账单**：阿里云控制台 → 费用与成本 → 账单管理 → 按「产品=对象存储 OSS」筛选；可设置费用预警（消费告警）。

## 九、安全清单

- [ ] AccessKey 只存在你的阿里云账户/RAM 中，不进代码、不进仓库、不进聊天
- [ ] 上传内容仅限 dist 产物；backend/、.env、数据库文件一律不上传
- [ ] Bucket 权限：静态站 Bucket 公共读；**其余 Bucket 保持私有**
- [ ] 不开启公共写；不需要开通跨域 CORS（纯静态同源）
- [ ] 若用 ossutil，凭据放本机配置文件（~/.ossutilconfig）并勿提交
